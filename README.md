# ❌⭕ Tic Tac Toe

A classic two-player Tic Tac Toe game built with HTML, CSS, and JavaScript. Take turns playing as X and O, and see who wins!

## 🌐 Live Demo

🔗 [Play the game here](https://pradipta762.github.io/Tic-Tac-Toe-Game/)

## 🛠 Tech Stack

- HTML  
- CSS  
- JavaScript

## ⚙️ Features

- Two-player turn-based gameplay
- Win/draw detection
- Game reset option
- Simple and responsive UI

## 💡 How to Play

1. Players take turns to place X and O on the grid.
2. The first to align three symbols (horizontally, vertically, or diagonally) wins.
3. If all cells are filled without a winner, the game ends in a draw.
